5.1 Foundations of Machine Learning


Machine learning is "the field of study that gives computers the ability to learn without being explicitly programmed" (Arthur Samuel, 1959). Learning itself is defined as the acquisition of new information or knowledge, or the process to acquire knowledge or skill by systematic study or by trial and error (Definition E4.1, adapted from the Encyclopedia of Neuroscience).

### The four components of a machine learning system

| Component | Symbol | Description |
| --------- | ------ | ----------- |
| Dataset | $\mathcal{S}$ | Set of samples generated by some system or process; single data points or input/output pairs |
| Model | $\mathcal{M}$ | Adjustable, compact representation of a class of input/output relationships, hypothesized to model the process generating $\mathcal{S}$ |
| Objective function | $\mathcal{L}$ | Encodes the current performance of $\mathcal{M}$ (loss or reward) |
| Algorithm | $\mathcal{A}$ | Learning algorithm that adjusts $\mathcal{M}$ based on $\mathcal{S}$ and $\mathcal{L}$ |

### The machine learning task

Train a model $\mathcal{M}$ in a hypothesis space $\mathcal{H}$ using a learning algorithm $\mathcal{A}$ so that $\mathcal{M}$ minimizes the loss $\mathcal{L}$ for a dataset $\mathcal{S}$. This form of learning is called **inductive learning**. The choice of $\mathcal{H}$ and $\mathcal{L}$ depends heavily on the properties of $\mathcal{S}$.

### The general workflow

Training data → features → learning algorithm (model $\mathcal{M}$) → feedback (data labels or reward signal), followed by execution with test and validation data.

**Feature selection**: many feature types exist (shapes, colors, histograms, filters). Choosing the right ones (feature engineering) is critical for performance, because the features must contain the information required for the prediction. All selected features are grouped into a **feature vector**.

### Programming vs. learning

Artificial cognitive systems act in complex dynamic environments where programming everything in advance is impossible, because

- the environment changes continuously (other agents, physical processes),
- dynamics and objects are too complex to be modeled explicitly (faces, animals, plants),
- the system itself is subject to change (growth, aging, injury, exercise, tool use).

Note the counterexample: not every impressive system learns. The Boston Dynamics WildCat relies on dynamic control algorithms and sensors, not on machine learning.

### Role in artificial cognitive systems

| Cognitive function | Contribution of machine learning |
| ------------------ | -------------------------------- |
| Learning and development | Modeling of biological learning mechanisms (operant conditioning, implicit and explicit learning) |
| Memory, knowledge, internal simulation | Encoding, storage and retrieval of facts, experiences and actions (associative memory) |
| Perception | Learning basic features to detect and categorize stimuli (unsupervised learning of visual features) |
| Autonomy | Dynamic adaption to environmental changes (continuous online learning from a live data stream) |

Typical applications: image classification, speech recognition, autonomous driving, recommendation systems, threat protection, control systems.
