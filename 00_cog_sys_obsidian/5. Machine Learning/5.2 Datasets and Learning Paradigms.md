5.2 Datasets and Learning Paradigms


The choice of a learning paradigm is in most cases directly motivated by the type of data available.

### Types of datasets

| Type | Formal definition |
| ---- | ----------------- |
| Unlabeled data | $\mathcal{S} = \{x_1, x_2, \dots, x_n\}$ |
| Labeled data | $\mathcal{S} = \{(x_1,y_1), (x_2,y_2), \dots, (x_n,y_n)\}$ |
| Mixed data | $\{(x_1,y_1), \dots, (x_n,y_n)\} \cup \{x_1, \dots, x_n\}$ |
| "Dynamic data" | $\mathcal{S} = \{(x_t,s_t) \mid s_{t+1} = \mathcal{D}(x_t,s_t) \wedge 0 \le t \le T\}$ with dynamical system $\mathcal{D}$ and system state $s_t$ |

Most real-world data is unlabeled (e-mails, images, video, measurements) and labeling is a tedious manual task. Natural datasets still carry structural features, which is the basis of big data and datamining. Examples: MNIST as a labeled dataset of 70,000 size-normalized, centered 28x28 handwritten digits; labeled audio files; dynamic robotic tasks with complex dynamics and unknown goal representation.

### The four learning paradigms

| Data | Paradigm | Characteristics |
| ---- | -------- | --------------- |
| Unlabeled | Unsupervised learning | Discovery of structural features in the dataset |
| Labeled | Supervised learning | All samples labeled, desired output specified exactly |
| Mixed | Semi-supervised learning | Labeled and unlabeled samples, a priori assumptions on the input data required |
| Dynamic environment | Reinforcement learning | Interaction with the environment, reward signal encodes feedback for the policy |

The paradigms differ in the amount of information provided during training, increasing from unsupervised over reinforcement and semi-supervised to supervised learning.

In practice, supervised learning requires manual labeling, and unsupervised learning is often applied to labeled datasets as a preprocessing tool for initial data analysis.

### Classification criteria of learning methods

| Criterion | Options |
| --------- | ------- |
| Type of learning | Supervised, semi-supervised, reinforcement, unsupervised |
| Model | Deterministic vs. stochastic, parametric vs. nonparametric, generative vs. discriminative |
| Value domain | Discrete (classification) vs. continuous (regression) |
| Reasoning | Inductive, deductive, transductive |
| Timing | Online vs. offline learning |
| Knowledge | Support for a priori knowledge |
| Agency | "Passive" vs. "active" learning |
