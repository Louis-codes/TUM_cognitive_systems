5.5.2 Classification


**Input**: a dataset $\mathcal{S} = \{(x_0,y_0), \dots, (x_N,y_N)\}$ with $x_i \in \mathbb{X}^K$ and $y_i \in \mathbb{C}$, where $\mathbb{C} = \{C_1, \dots, C_L\}$ is a discrete space of classes.
**Desired output**: a classifier $h: \mathbb{X}^K \rightarrow \mathbb{C}$ that predicts $y_n$ with minimum error.

Each $x_i$ is assigned to exactly one class, so the classes divide the input space into **decision regions**. Two classes ($\mathbb{C} = \{0,1\}$) are called binary classification; $K$ classes are represented with a 1-of-$K$ coding scheme.

### Generalized linear models

Linear regression produces $y_{reg}(x_n,w) = \sum_{j=0}^{M} w_j\phi_j(x_n)$ mapping to a continuous space. Classification requires an additional nonlinear activation function $f$ that discretizes the output:

$$y_{cls}(x_n,w) = f\Big(\sum_{j=0}^{M} w_j\phi_j(x_n)\Big)$$

$y_{cls}$ is a **generalized linear model**. Subspaces with $y_{cls}(x_n,w) = c$ are called **decision surfaces** and are linear functions of $x$. Analog neuron models are generalized linear models.

### Linear separation for binary classification

Two classes are separated by a linear discriminant function $y(x_n,w) = w^Tx_n = c^*$. The most common activation function is the Heaviside step function, giving the decision surface $w^Tx_n = 0$, which divides the sample space into two half-spaces.

### Classifying multiple classes

| Approach | Construction | Problem |
| -------- | ------------ | ------- |
| One-versus-the-rest | $K-1$ binary discriminant functions, each separating one class from all others | Ambiguous regions |
| One-versus-one | $K(K-1)/2$ pairwise discriminant functions, class assigned by majority vote | Ambiguous regions |

Both fail because the regions defined by the discriminant functions overlap or do not cover the whole input space. The solution is a true partition: every class $C_k$ gets its own linear function $y_{C_k}(x_n,w_k) = w_k^Tx_n$ and a sample is assigned to

$$C^* = \arg\max_{C_k \in \mathbb{C}} y_{C_k}(x_n,w_k)$$

The resulting decision regions are always **convex**, since for $\hat{x} = \lambda x_A + (1-\lambda)x_B$ the linearity of $y_{C_k}$ implies $y_{C_k}(\hat{x}) = \lambda y_{C_k}(x_A) + (1-\lambda)y_{C_k}(x_B)$.

### Representing classes: one-hot encoding

Choosing $\mathbb{C} = \{1,2,\dots,L\}$ takes class identifiers from an ordered set and thereby imposes a non-existing order on the classes that the model may capture. One-hot encoding avoids this latent information: for $L$ classes set $\mathbb{C} = \mathbb{R}^L$ and assign $c_k = (0,\dots,0,1,0,\dots,0)^T$ with a single 1 at position $k$.

### Least squares for classification

One-hot encoding maps classification to a regression problem solvable with least squares. Grouping all class models gives $y(x_n,W) = W^Tx_n$ with $W = (w_0 \ \dots \ w_L)$ and the loss

$$\mathcal{L}_\mathcal{S}(W) = \frac{1}{2}\mathrm{Tr}\{(XW-Y)^T(XW-Y)\} \longrightarrow W = (X^TX)^{-1}X^TY$$

The trace operator ensures that only the quadratic terms on the diagonal account for the loss. Main weakness: least squares classification is highly sensitive to outliers.

### Support Vector Machines

With least squares, the hyperplane depends on all samples, and for linearly separable input one of infinitely many solutions is computed. **SVMs** minimize the generalization error by maximizing the **margin**, the smallest distance between decision boundary and training samples (motivated by computational learning theory).

With $y(x) = w^T\phi(x) + b$ and $\mathbb{C} = \{-1,1\}$, all correctly classified examples fulfil $t_n y(x_n) > 0$, and the distance is $d(x_n) = \frac{t_n(w^T\phi(x)+b)}{\lVert w \rVert}$. Rescaling $w$ and $b$ so that the closest point satisfies $t_n(w^T\phi(x^*)+b) = 1$ yields the optimization problem

$$\arg\min_{w,b} \lVert w \rVert \quad \text{subject to} \quad t_n(w^T\phi(x)+b) \ge 1 \ \text{for all samples}$$

solvable with quadratic programming.

- The solution is a set of **support vectors** from the training data that define the decision boundary.
- After training, all samples except the support vectors can be discarded.
- **Slack variables** allow samples inside the margin, improving generalization for overlapping classes.
- Unlike least squares classification, outliers do not affect the result.
