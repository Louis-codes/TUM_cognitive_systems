5.5 Supervised Learning


Supervised learning operates on fully labeled datasets in which the desired output is specified exactly. Depending on the value domain of the target values, the task is either regression (continuous) or classification (discrete).

### The two basic tasks

| Task | Target space | Desired output |
| ---- | ------------ | -------------- |
| Regression | Continuous $\mathbb{Y}^L$ (e.g. $\mathbb{R}^L$) | A regressor $h: \mathbb{X}^K \rightarrow \mathbb{Y}^L$ predicting $y_n$ with minimum loss $\mathcal{L}$ |
| Classification | Discrete class space $\mathbb{C} = \{C_1, \dots, C_L\}$ | A classifier $h: \mathbb{X}^K \rightarrow \mathbb{C}$ predicting $y_n$ with minimum error |

Both tasks share the same underlying machinery: a linear basis function model provides the hypothesis space, and least squares provides the learning algorithm. Classification adds a nonlinear activation function that discretizes the output space.

The scikit-learn algorithm cheat sheet gives a practical overview of which method to select depending on data size, labeling and the type of prediction (classification, regression, clustering, dimensionality reduction).
