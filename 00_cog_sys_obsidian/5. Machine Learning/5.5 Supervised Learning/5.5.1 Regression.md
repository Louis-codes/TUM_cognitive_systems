5.5.1 Regression


**Input**: a dataset $\mathcal{S} = \{(x_0,y_0), \dots, (x_N,y_N)\}$ with $x_i \in \mathbb{X}^K$ and $y_i \in \mathbb{Y}^L$, a continuous target space $\mathbb{Y}^L$ and a loss function $\mathcal{L}: \mathbb{Y}^L \times \mathbb{Y}^L \rightarrow \mathbb{R}$.
**Desired output**: a regressor $h: \mathbb{X}^K \rightarrow \mathbb{Y}^L$ that predicts $y_n$ for a given $x_n$ with minimum loss.

### Linear basis function models

A class of hypothesis spaces formed by linear combinations of functions on the samples:

$$h_w(x_n) = w_0 + \sum_{j=1}^{M} w_j \phi_j(x_n) = w^Tx_n \quad \text{with } \phi_0(\cdot) = 1$$

The $\phi_j(\cdot)$ are the **basis functions**, the values $\phi_j(x_n)$ the **features** of $x_n$.

| Basis function | Definition | Resulting model |
| -------------- | ---------- | --------------- |
| Linear | $\phi_j(x_n) = x_n$ | Linear regression |
| Powers | $\phi_j(x_n) = x_n^j$ | Polynomial regression |
| Radial | $\phi_j(x_n) = \exp\left(-\frac{(x_n-\mu_j)^2}{2s^2}\right)$ | RBF model |
| Sigmoid | $\phi_j(x_n) = \sigma\left(\frac{x_n-\mu_j}{s}\right)$, $\sigma(z) = \frac{1}{1+e^{-z}}$ | Sigmoidal model |

### The sum-of-squares error

$$\mathcal{L}_\mathcal{S}(h_w) = \frac{1}{2}\sum_{n=1}^{N}\big(h_w(x_n) - y_n\big)^2 \qquad \mathcal{L}^*_\mathcal{S}(h_w) = \mathcal{L}_\mathcal{S}(h_w) + \frac{\lambda}{2}\lVert w \rVert^2$$

The optional regularization term punishes complex solutions. Learning a locally optimal weight vector corresponds to minimizing $\mathcal{L}$ or $\mathcal{L}^*$ with respect to $w$.

**Interpolation vs. regression**: an interpolation function must be consistent with $\mathcal{S}$ ($f(x_i) = y_i$), while a regression hypothesis should minimize $\mathcal{L}$ and generalize well to new samples.

### Learning $w$ with least squares

Find $w^*$ with $\nabla \mathcal{L}_\mathcal{S}(h_w) = 0$. The solution is

$$\phi^T\phi\,w^* = \phi^T y \longrightarrow w^* = (\phi^T\phi)^{-1}\phi^T y$$

with the design matrix $\phi$ of entries $\phi_j(x_n)$ and the target vector $y$. Geometrically, this is an orthogonal projection of $y \in \mathbb{R}^{N+1}$ onto the subspace $\mathcal{V}_\mathcal{H}$ spanned by the column vectors of $\phi$.

### Learning $w$ with maximum likelihood

The prediction error is interpreted as a noise term, $y_n = h_w(x_n) + \epsilon$, usually modeled as a Gaussian with mean $h_w(x_n)$ and precision $\beta$:

$$P(y_n \mid x_n, w, \beta^{-1}) = \mathcal{N}(y_n \mid h_w(x_n), \beta^{-1})$$

Maximizing the log-likelihood yields

$$\ln P(y \mid x,w,\beta) = -\frac{\beta}{2}\sum_{n=1}^{N}\big(h_w(x_n)-y_n\big)^2 + \frac{N}{2}\ln\beta - \frac{N}{2}\ln 2\pi$$

which amounts to minimizing $\sum_n (h_w(x_n)-y_n)^2 = 2\mathcal{L}_\mathcal{S}(h_w)$.

For linear basis function models with Gaussian prediction error, maximizing the log-likelihood is equivalent to computing the least squares solution.
