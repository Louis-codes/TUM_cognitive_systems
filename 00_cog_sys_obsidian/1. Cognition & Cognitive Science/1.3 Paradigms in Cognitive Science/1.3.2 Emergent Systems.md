1.3.2 Emergent Systems


Emergence is "the rise of a system that cannot be predicted or explained from antecedent conditions" (Encyclopædia Britannica). The main goal of cognitive processing in an emergent system is to maintain and extend its autonomy.

- Emergence is based on continuous self-organization of the system.
- An emerging system develops its own model of reality through interaction with the environment and filtering of relevant information.
- In contrast to the computational functionalism of cognitivism, knowledge and representation are specific to the system and depend on its history of interaction (→ experience).
- Knowledge is acquired in the form of additional anticipatory skills.
- Emergent systems necessarily require embodiment and development.

### Connectionist approaches

Connectionist cognitive systems model cognition based on networks of simple interconnected computational units. Processing is distributed, parallel, and based on statistical properties instead of formal rules.

Main components (Bechtel and Abrahamsen, 2002):

- simple elements called units,
- equations determining an activation value for each unit at each point in time,
- weighted connections allowing the activity of one unit to influence others,
- optionally learning rules that change the network's behavior by changing the connection weights.

Knowledge is stored in the connection weights. The most prominent class of connectionist systems are neural networks.

### Enactive approaches

An enactive emergent system "develops its own understanding of the world around it through its interactions with the environment" (Vernon, 2014). Enaction is governed by two mechanisms:

| Mechanism | Description |
| --------- | ----------- |
| Phylogeny | The interaction between system and environment is structurally determined by the innate embodied physical and cognitive capabilities |
| Ontogeny | The system is structurally coupled with the environment and makes sense of it based on its actions and the perception of the resulting reactions of the environment |

Through sense-making the system generates its own specific epistemology, increasing its cognitive capacity by capturing the regularities of interaction (→ exploration). The gradual increase of cognitive capacity results in development.

### Dynamical approaches

Dynamical emergent models are based on time-dependent differential equations, which allow a compact representation of complex system behavior and the application of dynamical systems theory (attractors, bifurcations, stability).

| Property | Description |
| -------- | ----------- |
| Dissipation | The number of reachable states reduces over time |
| Non-equilibrium system | Stable function requires an external "energy" supply |
| Non-linearity | Complex behavior can emerge from a small set of state parameters |
| Collective variables | The system is represented by a small set of state variables |

**Representation**: dynamical systems can, but need not, represent entities by system states or trajectories; such representations are transient and context-dependent.

**Role of time**: time is an active factor of computation that co-determines system behavior, and the synchrony between agent and environment constrains the processing speed of the system.

**Relation to connectionism**: connectionist systems can be dynamical systems (for example through recurrent connectivity), while connectionist modeling addresses the microscopic level.
