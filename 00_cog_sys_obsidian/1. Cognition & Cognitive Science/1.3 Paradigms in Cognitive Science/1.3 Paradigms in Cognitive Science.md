1.3 Paradigms in Cognitive Science


Cognitive science splits into two opposing paradigms plus their combination (Vernon, 2014):

- **Cognitivist systems**: cognition is a form of computation, cognitive functions are modeled as working computer programs.
- **Emergent systems**: cognition is a continuous self-organizing process driven by the interaction between agent and environment. Emergent approaches divide into enactive, connectionist and dynamical.
- **Hybrid systems**: combination of both.

### Comparison

| Characteristic | Cognitivist | Emergent |
| -------------- | ----------- | -------- |
| Role of cognition | Rational goal-achievement | Self-maintenance and self-development |
| Computational operation | Syntactic manipulation of symbols | Concurrent self-organization of a network |
| Representational framework | Patterns of symbols and tokens | Global system states |
| Temporal constraints | Atemporal | Synchronous real-time entrainment |
| Embodiment | No role implied, functionalist | Direct constitutive role, non-functionalist |
| Perception | Abstract symbolic representations | Perturbation by the environment |
| Action | Causal result of a symbol manipulation | Perturbation by the system |
| Adaption | Learn new knowledge | Develop new dynamics |
| Motivation | Criteria for goal selection | Increase space of interaction |

From Vernon (2014).
