2.1.1 Classification of Cognitive Architectures


Cognitive architectures are classified along the same paradigms as cognitive science itself. Kotseruba and Tsotsos (2018) survey 84 architectures and sort them into three types.

| Type | Timeline observation |
| ---- | -------------------- |
| Symbolic | Particular interest from the mid-1980s until the early 1990s |
| Emergent | Many of them biologically inspired, distributed fairly evenly over the timeline, but a relatively small group |
| Hybrid | Most newly developed architectures after the 2000s are hybrid |

### Cognitivist cognitive architectures

A cognitivist cognitive architecture models those aspects of cognition that are independent from the task and constant over time:

- it only specifies basic components and processes such as memory, knowledge representations and learning,
- it is a generic model reflecting a specific set of assumptions about cognitive processing (experimental data, philosophical arguments, hypotheses),
- the architecture is a framework that does not include any domain knowledge required for cognitive processing.

### Production systems

Reasoning and problem solving in many cognitivist cognitive architectures is implemented by production systems, containing rules of the form

```
if <conditions> then <actions>
```

- the conditions are propositions stating properties of and relations among the components of the system, usually stored in a working memory,
- a production is activated, i.e. its actions are executed, when all of its conditions are satisfied,
- when the conditions of more than one production are satisfied, precedence rules determine which one is executed,
- production systems are Turing complete and can adapt.

### Emergent cognitive architectures

In emergent systems, a cognitive architecture "is the framework that facilitates development" (Vernon, 2014):

- it models the phylogenetic configuration of a newborn agent (its innate skills) without any requirement for functional modularity,
- the body is an active part of the architecture,
- during ontogeny, the architecture is instantiated through the acquisition of experience, as opposed to manually designed knowledge bases in cognitivist architectures,
- it must provide a structure that accommodates different cognitive functions (perception, action, learning),
- as a result of development, the architecture can change over time.
