2.2.2 Declarative Module and Chunk Activation


The declarative module implements a storage of chunks that comprises the declarative memory of the system and ensures long-term personal and cultural coherence.

- Once a request is written to the buffer, the module searches the internal memory and returns the chunk that matches best in its retrieval buffer.
- New memories are collected automatically from the buffer when a module is cleared; equivalent chunks are merged.
- Two modes of retrieval are supported: purely **symbolic matching** with a random or deterministic selection process for matching chunks, and **time-aware** matching and selection based on sub-symbolic activation dynamics.

### Chunk activation

Every chunk $i$ in the declarative memory is assigned an activation $A_i$:

$$A_i = B_i + S_i + P_i + \varepsilon_i$$

| Term | Meaning |
| ---- | ------- |
| Base-level activation $B_i$ | Recency and frequency of use of the chunk |
| Spreading activation $S_i$ | Effect of the contents of the module buffers |
| Partial matching value $P_i$ | Matching-degree of the chunk for the request |
| Noise $\varepsilon_i$ | Noise value with a transient and a permanent component |

### Base-level activation

$$B_i = \ln\Big(\sum_{j=1}^{n} t_j^{-d}\Big) + \beta_i$$

with $n$ the number of presentations (entry into memory or merge with another chunk) of chunk $i$, $t_j$ the time since the $j$-th presentation, $d$ the decay parameter and $\beta_i$ a constant offset.

### Spreading activation

Determined by all buffers $k$ that currently contain a chunk which has a slot storing another chunk with a positive activation value:

$$S_i = \sum_k \sum_j W_{kj} S_{ji}$$

with $W_{kj}$ the amount of activation from source $j$ in buffer $k$ and $S_{ji}$ the association strength from source $j$ to chunk $i$.

### Partial matching

Computed by iterating over all slot values $k$ of the retrieval specification:

$$P_i = \sum_k P M_{ki}$$

with $P_i$ the match scale parameter determining the importance of similarity and $M_{ki}$ the similarity value between the desired and the actual slot value, usually a negative penalty.
