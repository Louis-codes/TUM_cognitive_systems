2.1 Monte Carlo (MC) Methods


MC performs the evaluation step of GPI **from experience**, without a model, by averaging actually observed returns.

### Gist

Run a complete episode, wait until it terminates, compute the realized return $G_t$, and average it into the estimate:

$$q(S_t,A_t) \leftarrow q(S_t,A_t) + \alpha\,\big[\,G_t - q(S_t,A_t)\,\big]$$

with $G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \dots$ taken from the episode itself.

### Properties

| Property | Value |
| -------- | ----- |
| Model required | No |
| Bootstrapping | No, uses only real returns |
| Bias | Unbiased |
| Variance | High, returns fluctuate strongly across episodes |
| Applicability | Episodic tasks only, must wait for termination |

### Why no bootstrapping matters

MC never learns from a guess: the target is the true sampled return. This makes it robust when the Markov property is violated, and makes each estimate independent of the accuracy of neighbouring states. The price is slow learning and no updates in continuing tasks that never end.
