2.2 Temporal Difference Learning (TD)


TD combines the sampling of MC with the bootstrapping of DP. It is the workhorse of modern RL.

### Gist

Do not wait for the episode to end. Use the Bellman recursion $G_t = R_{t+1} + \gamma G_{t+1}$ and replace the unknown remainder by the current estimate:

$$v(S_t) \leftarrow v(S_t) + \alpha\,\big[\,\underbrace{R_{t+1} + \gamma\,v(S_{t+1})}_{\text{TD target}} - v(S_t)\,\big]$$

The bracket is the **TD error**, the surprise between the old guess and the better one. Applied to action values:

$$q(S_t,A_t) \leftarrow q(S_t,A_t) + \alpha\,\big[\,R_{t+1} + \gamma\,q(S_{t+1},A_{t+1}) - q(S_t,A_t)\,\big]$$

### Properties

| Property | Value |
| -------- | ----- |
| Model required | No |
| Bootstrapping | Yes, learns an estimate from an estimate |
| Bias | Biased |
| Variance | Low, only one transition per update |
| Applicability | Online, step by step, works on continuing tasks |

### Variants

**SARSA** (on-policy): the target uses the action the policy actually took, $q(S_{t+1},A_{t+1})$.
**Q-learning** (off-policy): the target uses the best action regardless of what was taken, $\max_{a'} q(S_{t+1},a')$, so it learns $q_*$ directly while behaving exploratively.
