2.3 Deep Reinforcement Learning (DRL)


All methods so far assumed $q(s,a)$ can be stored as a **table**, one entry per state-action pair. Go has more than $10^{80}$ states and Atari one state per pixel configuration, so the table neither fits nor could ever be visited entirely.

### Gist

Replace the table by a parameterized function, typically a neural network:

$$q(s,a) \approx \hat{q}(s,a;\mathbf{w})$$

Instead of writing into a cell, perform gradient descent on the squared TD error:

$$L(\mathbf{w}) = \Big(\underbrace{R_{t+1} + \gamma \max_{a'} \hat{q}(S_{t+1},a';\mathbf{w}^-)}_{\text{target}} - \hat{q}(S_t,A_t;\mathbf{w})\Big)^2$$

This is **DQN**, the algorithm behind the Atari results (Mnih et al., 2015).

### What is gained

**Generalization.** A table learns nothing about state 501 from having seen state 500. A network maps similar inputs to similar outputs, so experience transfers to unvisited states. This is the only reason RL scales to raw pixels or continuous state spaces.

### What is lost

Tabular GPI provably converges. With function approximation the target itself depends on the weights being updated, so training can diverge. The stabilizing tricks exist purely for this reason:

| Trick | Purpose |
| ----- | ------- |
| Frozen target network $\mathbf{w}^-$ | Keeps the regression target fixed for a while |
| Experience replay buffer | Breaks the correlation between consecutive samples |

### Policy-based variants

Instead of a value function, the policy itself can be a network, $\pi(a\mid s;\boldsymbol{\theta})$, trained by policy gradients (REINFORCE, PPO, A2C, SAC). This is also what makes **continuous action spaces** feasible, since no $\arg\max$ over an infinite action set is needed.

### Mental model

The theory in the foundations notes is the exact solution for small problems. DRL is the same theory with the table swapped for a network, plus engineering to keep it stable.
