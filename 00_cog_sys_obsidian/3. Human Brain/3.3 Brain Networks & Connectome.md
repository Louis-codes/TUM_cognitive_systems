3.3 Brain Networks & Connectome


The brain is a highly complex network of interconnected cells and modules.

### Key properties

- Connectivity is both static (anatomical connectivity) and dynamic (functional connectivity, dependent on the current cognitive task).
- Brain networks can be described as graphs and analyzed with graph theory.
- The network topology is analyzed with standard graph-theoretic measures: node degrees, clustering coefficients, hubs, path lengths.
- Brain networks are thought to be related to information integration (integrated information theory).

### Data and tools

- Anatomical connectivity is measured e.g. with DTI (diffusion tensor imaging).
- Connectome databases such as the Allen Mouse Brain Atlas provide experimental projection data (http://connectivity.brain-map.org/projection).
