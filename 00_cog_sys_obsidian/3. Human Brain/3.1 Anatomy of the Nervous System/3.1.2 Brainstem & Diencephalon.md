3.1.2 Brainstem & Diencephalon


The brainstem (Hirnstamm) connects the cerebrum with the spinal cord. It is divided into four sections.

### Sections

| Section                          | German            | Function                                                                         |
| -------------------------------- | ----------------- | -------------------------------------------------------------------------------- |
| Diencephalon                     | Zwischenhirn      | Four sub-structures, see below                                                    |
| Midbrain (Mesencephalon)         | Mittelhirn        | Control of eye movements (visual reflexes, object tracking), auditory and visual processing |
| Pons                             |                   | Nerve fibers connecting medulla oblongata and cortex with the cerebellum; transmits sensory and motor signals to the facial region |
| Medulla Oblongata                | Verlängertes Mark | Connects the brain with the spinal cord                                           |

### Sub-structures of the diencephalon

| Structure     | Function                                                                                  |
| ------------- | ----------------------------------------------------------------------------------------- |
| Epithalamus   | Production of the hormone melatonin (biological clock)                                     |
| Thalamus      | Relay and distribution of sensory and motor signals to the regions of the cerebral cortex  |
| Hypothalamus  | Control of autonomic functions (temperature regulation, appetite), behavior, hormone production |
| Subthalamus   |                                                                                            |

### Naming schemata

Different schemata exist for denominating brain components. For example, pons, medulla oblongata and the cerebellum (Kleinhirn) together form the hindbrain (Rautenhirn).
