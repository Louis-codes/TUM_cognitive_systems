3.5.1 Analog Neuron Models


Analog neurons produce a real-valued output that can be interpreted as a firing rate.

### The analog neuron

The simple McCulloch-Pitts model has been generalized by adding synaptic weights and an activation function. The output of a neuron $n$ with activation function $A$, synaptic weights $w$, bias $b$ and input $x$ is

$$n(x) = A(w_1x_1 + \dots + w_nx_n + b) = A(w^Tx + b)$$

### Common activation functions

| Function                     | Definition                                          |
| ---------------------------- | --------------------------------------------------- |
| Binary step                  | $A(x) = 0$ for $x < 0$, $1$ for $x \ge 0$           |
| Logistic                     | $A(x) = \frac{1}{1+e^{-x}}$                         |
| tanh                         | $A(x) = \tanh x$                                    |
| Rectified Linear Unit (ReLU) | $A(x) = 0$ for $x < 0$, $x$ for $x \ge 0$           |
| Exponential Linear Unit (ELU)| $A(x) = \alpha(e^x - 1)$ for $x < 0$, $x$ for $x \ge 0$ |
| Gaussian                     | $A(x) = e^{\alpha(x-t)^2}$                          |

### Historical milestones

| Year | Milestone                                                                                                                          |
| ---- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 1943 | McCulloch and Pitts model the nervous system as networks of interconnected cells encoding formal logic; two states (firing/resting), a cell fires only if its input crosses a threshold. Considered the starting point of modern AI |
| 1957 | The Perceptron (Frank Rosenblatt): a single neuron learning to classify input patterns by adapting synaptic weights from falsely classified samples; initially built as a physical system with motors and potentiometers |
| 1960 | ADALINE (Widrow): adaptive pattern classification machine trained on desired outputs; experience stored in the weights, iterative search converges (also statistically on noisy patterns) |
| 1969 | AI winter: Minsky and Papert prove in *Perceptrons* that the perceptron only works for linearly separable data sets. It ends with new architectures (Hopfield, Kohonen) and the backpropagation algorithm (Werbos) |
