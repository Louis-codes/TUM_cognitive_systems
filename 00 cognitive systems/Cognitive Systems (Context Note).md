Context note for LLM chats. Anyone reading this vault should understand here what it contains and then jump into the matching sub note.

### Purpose

This vault collects and structures the material of the module "Cognitive Systems: Neural Networks and Applied AI" at the Technical University of Munich (TUM). It serves as a knowledge base for the six sub domains covered in the module.

### The six sub domains

1. Cognition & Cognitive Science
2. Cognitive Architectures, ACT-R & Large Language Models (LLMs)
3. Human Brain
4. Biological Neurons & Spiking Neural Networks
5. Machine Learning
6. Reinforcement Learning

### Structure

Each sub domain has its own folder containing a main note of the same name. Further notes on individual topics belong inside the corresponding sub domain folder. Topics spanning several sub domains stay in the root directory.

### Notes for LLM chats

The vault is under construction, most notes are still scaffolds. New content belongs in a separate sub note inside the matching folder, not in this overview. Extend this note only by adding an entry to the topic list.

This note deliberately contains no wikilinks. Linking runs exclusively upward from the sub notes to this context note, so the graph keeps its star shaped structure. Names in the list are plain text references and must not be converted into links.

Answers should be concise and tabular. Where a statement is an estimate, this is marked in the note.
